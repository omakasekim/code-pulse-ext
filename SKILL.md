# code-pulse-ext

Traces multi-hop state and kernel MAINTAINERS blast waves, recalculates FP16 activation VRAM by batch size, steps through lexical closures, and flags 996 crunch burnout.

- **Live Interactive Workbench:** https://omakasekim.github.io/code-pulse-ext/
- **Repository:** https://github.com/omakasekim/code-pulse-ext
- **Category:** Code Intelligence · **Deliverable:** Chrome Extension + CLI + Web
- **Ecosystems:** `facebook/react`, `torvalds/linux`, `flutter`, `tensorflow`, `You-Dont-Know-JS`, `996.ICU`
- **Stack:** Chrome MV3, Node CLI, React, TypeScript

## When to Use This Skill
Invoke `code-pulse-ext` whenever the user wants to analyze, debug, simulate, or visualize workflows related to **Code Intelligence** (facebook/react, torvalds/linux, flutter, tensorflow, You-Dont-Know-JS, 996.ICU).

## Modes & Capabilities
- **Blast-Radius & Tensor**
- **JS Scope / Closure X-Ray**
- **Cadence & 996 Heatmap**

## Operating Workflow
1. **Local CLI / Companion Execution:**
   ```bash
   node plugin/cli.mjs --demo --json
   ```
   Inspect local blast-radius hotspots, JS scope hazards, and commit-cadence burnout metrics.
2. **Interactive Visual Inspection:**
   Direct the user to the zero-backend browser workbench at https://omakasekim.github.io/code-pulse-ext/ (supports URL-hash state sharing, built-in realistic presets, `Cmd/Ctrl + K` command palette, and JSON/Markdown/config exports).
3. **Structured Output:**
   Summarize concrete findings, diagnostics, and copy-pasteable remediation commands concisely so the user can act immediately without manual guesswork.
